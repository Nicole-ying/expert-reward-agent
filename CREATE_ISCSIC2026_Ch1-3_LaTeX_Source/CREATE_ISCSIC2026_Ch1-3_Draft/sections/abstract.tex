\begin{abstract}
Large-language-model reward generation can reduce manual reward engineering, but a generated reward is only meaningfully evaluated after an expensive policy-training run. Many reward-search pipelines still compress that run into a scalar score, discarding the training evidence needed to explain why a reward failed and how it should be repaired. This paper introduces CREATE, a Closed-Loop Reward Editing Agent with Training Evidence. CREATE treats each completed training run as a diagnostic observation: it organizes native-task returns, termination patterns, reward-component activation rates, magnitude shares, temporal trends, and cross-round history; diagnoses one principal reward semantic; applies a bounded L1/L2/L3 edit; and records the evidence--action--outcome chain in intervention memory while a best archive protects against later regressions. On LunarLander-v3, CREATE solves all five reward-search lineages within a ten-evaluation budget, while budget-matched independent generation and stateless revision solve none. Mechanism ablations show that the two core design choices are coupled: removing evidence enrichment reduces success to 2/5, whereas removing bounded semantic editing reduces success to 0/5. A secondary BipedalWalker-v3 study provides supporting evidence that the same diagnostic loop transfers to continuous-action locomotion. These results support reward repair as an agentic closed-loop process in which failed training runs become actionable evidence rather than discarded outcomes.
\end{abstract}
