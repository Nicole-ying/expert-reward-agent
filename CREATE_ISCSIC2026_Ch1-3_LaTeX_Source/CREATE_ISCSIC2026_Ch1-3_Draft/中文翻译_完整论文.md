# CREATE: 基于训练证据的闭环奖励编辑智能体

**（完整论文直译）**

---

## 1. 引言

强化学习通过与环境的交互获取决策策略，已应用于机器人、自主系统、游戏和复杂决策。奖励函数是任务意图与策略优化之间的接口：它必须表达期望的行为，同时提供信息丰富且可学习的反馈。然而，一个语义上看似合理的奖励仍可能因稀疏信号、冲突组件、不恰当的尺度、限制性门控或可利用的代理目标而失败，从而降低学习效率和最终行为质量。

因此，奖励工程是一个迭代过程：任务分析、奖励实现、策略训练、行为检查和修订。一次完整的训练运行产生的不只是任务回报。Episode长度、终止模式、行为结果、组件激活、组件尺度及其在训练过程中的演变，可以揭示奖励程序如何塑造学习到的策略。然而，将这些异构记录转化为精确的奖励修改，目前仍然需要大量的人工分析。

具有代码能力的大语言模型为自动化这一过程提供了新途径。Language to Rewards和Text2Reward将任务描述和环境接口翻译为可执行的奖励程序；Eureka将奖励代码生成与进化优化和奖励反思相结合；后续工作融合了动态反馈、结构化推理、人类反馈和诊断精化。这些研究确立了LLM可以生成并迭代改进奖励函数，同时也表明奖励质量只有在训练出相应策略之后才能被观测到。

与此同时，语言模型越来越多地被组织为智能体——它们对观测进行推理、与外部工具交互、并跨试验保留经验。ReAct将推理与环境行为交织在一起，而Reflexion和Self-Refine则利用先前尝试的反馈来改进后续决策。这些发展催生了一种面向智能体的奖励工程视角：策略训练提供观测，奖励代码修构成外部行为。

本文通过CREATE——一个基于训练证据的闭环奖励编辑智能体——来探索这一视角。CREATE将奖励编辑智能体置于内部的RL策略学习器之上。每次策略训练运行后，一个辅助的工具使用子智能体将原生任务结果、终止行为、奖励组件统计和训练动态检索并压缩为聚焦的证据摘要。奖励编辑智能体是唯一的决策者：它识别一个主要的奖励语义，选择一个修复级别，并施加一次语义局部化的奖励编辑。干预记忆保留观测、假设、编辑、预测和结果，而独立的最佳存档保护最强的可执行奖励。

主要基线和消融研究在LunarLander-v3上进行。预算匹配的独立生成和无状态迭代修订分别测试候选方案数量或重复重写是否单独解释了改进，而两个消融分别隔离了证据富集和层级语义编辑。BipedalWalker-v3被用作完整CREATE工作流在连续动作运动上的辅助跨任务验证，不在该环境上进行基线对比。综合来看，这些实验考察了结构化观测、持久状态和有界奖励行为能否在十次评估预算内将失败的策略训练转化为可靠的奖励修复。

## 2. 相关工作

### 2.1 强化学习的奖励工程

奖励塑形通过提供改善信用分配和探索的中间信号来增强任务目标。势基塑形确定了一类保持最优策略的变换，而奖励机通过显式自动机暴露任务结构。逆奖励设计将指定的奖励视为设计者意图的不完美证据。相关方法从示范或偏好中推断目标，或从新颖性和预测误差中构建内在奖励。这些方法减少了直接的手动调整，但通常需要设计者指定的特征、示范、偏好数据或预定义的奖励表示。

奖励函数也被视为搜索和优化的对象。进化方法、元梯度和基于行为的目标根据策略训练结果调整奖励参数或结构。这种从手动固定奖励到可修订奖励程序的转变为基于语言模型的奖励工程提供了基础。

### 2.2 基于LLM的奖励生成与精化

LLM可以将自然语言目标和环境接口映射为可执行的奖励代码。Language to Rewards为机器人技能生成稠密奖励程序，Text2Reward为操作和运动产生可解释的自由形式奖励。Eureka将生成扩展到进化奖励代码优化，并使用组件反馈指导后续候选方案。REvolve将人类反馈纳入奖励演化，而CARD将奖励生成与动态反馈和轨迹级评估相结合。

迭代精化也通过显式推理被组织起来。Self-Refine展示了LLM可以通过重复反馈而不更新参数来改进输出。CoT奖励工程框架将任务理解、奖励组件构建、性能分析、行为分析和改进规划分解为结构化的推理过程。诊断驱动的精化进一步将奖励失败视为调试问题，并使用训练诊断来指导有针对性的修订，同时识别连续控制中的校准限制。综合来看，这些方法表明训练反馈可以支持超越单次生成的奖励修订。

### 2.3 LLM智能体与智能体化奖励工程

语言智能体研究考察LLM如何在外部过程中保持状态并采取行动。ReAct将推理与工具介导的行为耦合，而Reflexion将先前试验的语言反馈存储为episodic经验。工具使用、专门化子智能体和持久记忆随后使得更长的自主工作流成为可能。

智能体化机制也正在进入奖励设计领域。RF-Agent将奖励构建表述为序列决策，并使用蒙特卡洛树搜索来组织候选生成和历史反馈。STRIDE应用智能体化工程来自动化人形运动的奖励设计、深度RL训练和反馈优化。CREATE遵循这一智能体化方向，但将交互接口置于经过仪器化的策略训练之上。其诊断子智能体将内部训练记录转化为观测，而奖励编辑智能体承诺一次语义局部化的编辑，其结果由下一次完整的训练运行来测量。

## 3. CREATE

CREATE由一个外部奖励编辑智能体和一个底层强化学习智能体组成。RL智能体与任务环境交互，在当前生成的奖励程序下学习策略。奖励编辑智能体以更慢的时间尺度运行：一次完整的策略训练和原生评估运行构成一轮奖励设计。如框架图所示，工具辅助的证据处理将相关训练和谱系记录检索并压缩为聚焦的观测，之后奖励编辑智能体诊断当前奖励，选择一个干预，并产生下一轮的经验证奖励程序。

由此产生的交互可表示为三个方程，其中D_t表示第t轮产生的训练和原生评估记录，L_t包含选定的跨轮谱系记录。工具辅助处理器Φ_tool产生紧凑的观测O_t，但不制定奖励假设或选择奖励编辑。奖励编辑智能体Ψ是唯一的决策者：它将O_t与当前奖励R_t、干预记忆M_t和最佳存档B_t结合起来，产生失败假设H_t和奖励行为A_t。语言模型参数在整个过程中保持不变；只有奖励代码和外部维护的智能体状态在演化。

### 3.1 任务理解与奖励初始化

给定任务描述、可访问的环境接口和奖励代码约束，CREATE识别一组紧凑的行为语义并将其实例化为命名的奖励组件。初始奖励为各项加权求和，其中每个组件代表一个与任务相关的语义，如进展、稳定性、目标事件、安全或动作代价。命名的组件在策略训练期间独立记录，使得它们的激活和贡献能够在后续奖励设计轮次中被检验。训练前，生成的程序会对照环境接口进行检查，并在采样转移上执行，以验证它返回有限标量奖励和有效的组件字典。

### 3.2 工具辅助观测与奖励编辑

在第t轮奖励设计中，底层RL智能体使用生成的奖励进行训练，而结果策略则使用未修改的环境原生目标进行评估。这种分离防止了生成的奖励自我评判。每次完成的运行产生原生任务结果、episode长度和终止统计、奖励组件激活、贡献幅度、时间训练趋势以及与前一奖励版本的差异。

直接将所有原始日志和累积记录放入编辑提示会大幅增加上下文长度，并可能分散奖励编辑智能体对当前干预决策的注意力。因此，CREATE使用一个辅助的工具辅助证据组织器来检索与决策相关的记录并将其压缩为结构化摘要。该组织器报告训练期间发生的情况，包括策略进展趋势、组件健康、奖励对齐和观测到的异常。它不推荐系数更改、不选择奖励变换、也不确定干预级别。这些决策仍然是奖励编辑智能体的职责。

最终编辑上下文包含当前奖励程序、紧凑的证据摘要、选定的跨轮对比、环境事实、干预历史和最佳存档奖励。组件统计被视为诊断线索而非确定性编辑规则。例如，一个持续不活跃的项可能表示不可达的事件或限制性门控，而一个频繁活跃且幅度过大的项可能主导学习信号。奖励编辑智能体将这些观测与策略结果和先前的干预结果结合起来，为下一次修订确定一个主要的奖励语义。

奖励行为表示为A_t = (q_t, l_t, Δ_t)，其中q_t是选定的奖励语义，l_t是干预级别，C(q_t)包含实现该语义的组件和参数。CREATE使用层级语义干预控制器，联合决定应该改变什么以及改变多深。Level 1通过调节系数、阈值或门控执行参数调整，同时保持当前组件形式。Level 2通过改变选定语义的数学形式执行组件重构，例如将不可达的稀疏事件替换为可达的稠密信号，或防止某一项主导奖励。Level 3仅在累积证据表明当前奖励分解不再能局部修复后执行结构重新规划。普通Level 1和Level 2行为保持局部化于一个主要语义。多条代码行或密切相关的参数在它们共同实现该语义时可以一起更改，但无关的设计意图不会在一次普通修订中混合。

### 3.3 谱系记忆与最佳奖励选择

每轮完成后，CREATE将紧凑观测、失败假设、选定语义、干预级别、预期行为变化和观测结果存储在持久谱系记忆中。该记忆允许后续决策比较预测效果和实际效果，避免重复不成功的修改，并区分暂时性回退与一贯无效的奖励结构。

由于顺序奖励演化不是单调的，最佳存档与活跃谱系分开维护。新生成的奖励可以在其表现低于历史最佳时被探索，而存档的优胜者仍受保护。在至多K次完整奖励评估后，CREATE返回argmax J_t对应的R*。存档存储完整的可执行奖励及其对应的原生评估记录。选定的奖励随后使用奖励编辑期间未暴露的评估种子进行检验。

## 4. 实验

### 4.1 实验设计

LunarLander-v3是基线对比和机制消融的主要基准。BipedalWalker-v3仅用作完整CREATE工作流在不同动作空间和控制结构下的额外验证；不在该任务上进行基线或消融对比。每个奖励程序训练一个全新初始化的PPO策略。LunarLander每个候选方案使用10^6环境步，BipedalWalker使用5×10^6，每个策略训练任务内使用四个向量化环境。每个条件包含五个独立的奖励搜索谱系，至多十次完整的奖励评估。

策略使用生成的奖励进行优化，而候选方案的质量仅通过未修改的环境奖励来衡量。我们将搜索适应度定义为20个固定评估episode上的平均未折现原生episodic回报，最佳搜索适应度定义为谱系中保留的最大值。奖励选择后，返回的策略在100个搜索期间未暴露种子的episode上进行评估，报告为测试适应度。任务解决阈值为LunarLander的200和BipedalWalker的300。

所有LunarLander条件使用相同的DeepSeek V4 Pro骨干、环境描述、奖励接口、代码检查和PPO预算。单次生成仅评估初始奖励。Independent-10将十次奖励评估用于不相关的初始候选方案。无状态迭代修订从基本的当前轮次反馈中反复修订当前奖励，但没有工具组织的证据、持久干预记忆、跨轮组件对比或层级语义编辑策略。两个消融分别移除证据富集或层级语义编辑，同时保留CREATE循环的其余部分。完整提示、模型设置、超参数和每种子的轨迹提供在补充材料中。

### 4.2 匹配训练预算下的奖励搜索

上表区分了候选数量、重复修订和完整闭环的效果。单次生成从未解决任务，表明初始看似合理的奖励并非可靠可学习。Independent-10尽管评估了与CREATE相同最大数量的奖励程序，也未解决任何谱系。因此，仅靠搜索广度无法恢复失败策略训练中包含的信息。

无状态修订将平均谱系最佳适应度提升至44.0，但仍未解决任何种子。在五个谱系中的三个，初始奖励已经是最佳版本，且最终修订在所有五个中都比存储的最佳更差。该过程因此产生非单调的重写，而没有累积可靠的进展。相比之下，CREATE在第8、10、2、4和3轮分别解决了所有五个谱系，平均需要5.4次完整奖励评估首次越过阈值。其选定的策略获得231.63±12.23的测试适应度，接近其搜索时的表现。

预算曲线图显示每种方法如何利用额外的策略训练评估。独立生成仅在不相关的另一个样本碰巧更好时才改善，而无状态修订尽管反复重写，仍达到低平台。CREATE逐步提升其保留的优胜者，并最终解决每个谱系。因此，关键区别不是重复的LLM调用本身，而是一次完成的策略训练运行是否成为约束下一次奖励行为的持久证据。

### 4.3 机制消融

移除证据富集后，编辑器仍拥有原生适应度、episode长度、终止统计和组件episode总和，但移除了工具使用的证据组织器、激活率、幅度占比、时间趋势和结构化跨轮摘要。此变体解决了两个种子，但表现出非常高的离散度，包括一个谱系在所有十轮中始终保持负值。基本组件值因此可以支持偶尔的修复，但不能可靠地区分不活跃、弱、饱和或行为上不可达的奖励项。

移除层级语义编辑后，保留了富集证据、记忆和最佳存档，但允许无约束的多组件重写。它在几个种子中达到中等适应度，但未解决任何一个，且一个谱系在连续两轮中崩溃至约-5511。失败不仅仅是信息不足：当几个不相关的组件同时更改时，一次后续的训练结果无法确定应该保留或回退哪个干预。CREATE则选择一个主要语义，并施加L1参数修复、L2组件重构或例外L3重新设计，使每次昂贵的重训练运行成为更聚焦的干预检验。

消融散点图使可靠性差异变得明确。证据贫乏的修复偶尔可以成功，但强依赖于初始化。无限制编辑的离散度较低仅因为所有五个谱系都保持在阈值以下。完整CREATE将5/5解决方案率与显著更紧的分布相结合，支持了将富集观测与有界奖励行为耦合的必要性。

### 4.4 代表性奖励修复模式

聚合结果未揭示组件证据如何转化为具体编辑。因此展示了三个成功的CREATE谱系，暴露了不同的失败模式。图中保留了分数轨迹和L1/L2/L3编辑标签，而详细的激活率和幅度占比热力图移至补充材料。

**崩溃与恢复。** 在种子0中，第1-6轮探索了系数缩放、稀疏到稠密转换和数学形式更改，但未解决任务。第7轮将基于状态的接近信号替换为差分进展塑形，崩溃至约-389。诊断记录将此次失败归因于信号在着陆器静止时接近零、在扰动下变为负值，无法提供稳定的着陆引导。第8轮的L2干预恢复了基于状态的公式，并添加了抑制奖励利用的高度因子，将适应度提升至224。最佳存档保护了此解，即使下一次探索性奖励跌至约-612。

**渐进收敛。** 种子3在将绝对距离惩罚替换为势差接近塑形后，从约-20改善至148。一次过度限制的调整随后导致暂时性回退。随后的L2编辑将接触语义重构为可达的梯度，提供从单腿接触到同时稳定接触的连续反馈，下一次策略达到254。与种子0不同，这些修订保持在一致的信号框架内，一次改变一个主要语义。

**代理目标错位修复。** 种子4从140开始，但在局部调整后回退。组件证据表明近地面接触转移奖励在弹跳期间被反复触发——每episode约75次——并主导塑形目标而非代表稳定着陆。L2修复将此转移代理目标替换为持久接触质量门控，在该门控下弹跳速度抑制奖励，仅有低速接触保持有利。下一个版本达到206并解决任务。

跨越三条路径，决定性编辑针对不同的缺陷——无信息梯度、不可达接触梯度和可奖励代理目标——但遵循相同的机制。组件激活和尺度识别出一个主要语义失败，编辑器执行有针对性的L2修订而非无限制重写。因此，这些轨迹通过展示富集证据和层级编辑如何在个别奖励谱系中交互，补充了消融结果。
